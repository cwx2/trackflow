# 查询面板

查询面板是 TrackFlow 的核心导航区域，位于工单列表页的左侧，灵感来自 YouTrack 的 Saved Query 功能，让你快速在不同的工单视图之间切换。

## 面板布局

查询面板从上到下分为五个区域：

```
┌─────────────────────────┐
│  🔍 过滤已保存的查询...  │  ← 查询列表过滤框
├─────────────────────────┤
│  ▾ 草稿                 │  ← 草稿区
├─────────────────────────┤
│  ▾ 项目                 │  ← 项目区
├─────────────────────────┤
│  ▾ 标签                 │  ← 标签区
├─────────────────────────┤
│  ▾ 已保存的搜索          │  ← 查询列表
└─────────────────────────┘
```

点击各区域的 **▾** 标题可以折叠/展开该区域。

---

## 草稿区

显示你未完成的工单草稿。当你开始创建工单但中途取消时，已填写的内容会自动保存为草稿。

**草稿操作**

- **点击草稿**：恢复编辑该草稿，右侧创建面板会自动填入已保存的内容
- **右键草稿**：弹出菜单，可删除单条草稿
- **点击「新建工单」**：清空草稿，重新开始创建

::: tip
草稿只保存在本地浏览器，不同设备、不同浏览器之间不共享。
:::

---

## 项目区

显示你收藏的项目列表，用于快速按项目过滤工单。

**项目列表**

- **所有项目**：显示你所有可访问项目的工单（默认选中）
- 收藏的项目：点击项目名，右侧工单列表只显示该项目的工单

**收藏项目**

点击项目区右上角的**管理收藏项目**（⭐ 图标），弹出项目选择列表，勾选想要显示在面板中的项目。

---

## 标签区

显示你收藏的工单标签，用于快速按标签过滤工单。

- 每个标签后面显示该标签下的工单数量
- 点击标签名，右侧工单列表只显示带该标签的工单
- 点击**管理标签收藏**可添加/移除收藏的标签

---

## 已保存的搜索

这是查询面板的核心区域，显示所有已保存的查询列表，每行显示查询名称和匹配的工单数量。

### 内置系统查询

以下查询为系统内置，所有用户都有，不可删除：

| 查询名 | 图标 | 说明 |
|--------|------|------|
| 分配给我 | 🎯 | 当前用户为负责人的工单 |
| 我报告的 | 🐛 | 当前用户创建的工单 |
| 未解决 | 📌 | 所有状态类别为 Open 或 In Progress 的工单 |
| 最近更新 | — | 按更新时间倒序排列的所有工单 |
| 我评论的 | — | 当前用户评论过的工单 |

### 自定义查询

除系统内置外，你可以创建自己的命名查询：

**创建查询**
1. 在工单列表右侧设置好筛选条件
2. 点击查询面板「已保存的搜索」右侧的 **+** 按钮
3. 输入查询名称，点击保存

**管理查询**

鼠标悬停在查询行右侧会出现 **⋯** 按钮，点击弹出菜单：

| 操作 | 说明 |
|------|------|
| 重命名 | 修改查询名称 |
| 编辑 | 修改查询的筛选条件 |
| 共享 | 将查询共享给其他团队成员 |
| 置顶 | 将查询固定到列表顶部 |
| 删除 | 删除该查询（系统查询不可删除） |
| 收藏 | 在查询名称前显示 ⭐ 标记 |

**共享查询**

共享后的查询对项目所有成员可见，显示在他们的查询面板中（标注「共享」来源）。

## 查询语法

在工单列表顶部的搜索框中，支持两种模式：

### 筛选模式（Filter）

点击**切换到筛选模式**（漏斗图标），以图形化的方式添加筛选条件：

1. 点击 **+** 添加筛选条件
2. 选择字段（状态、负责人、优先级、Sprint 等）
3. 选择操作符（等于、不等于、包含等）
4. 输入或选择筛选值

多个筛选条件之间为 **AND** 关系（同时满足）。

### 搜索模式（Search）

点击**切换到搜索模式**（搜索图标），在输入框中直接输入结构化查询语法：

```
字段名: 值 字段名: 值 ...
```

**支持的字段**

| 字段 | 说明 | 示例 |
|------|------|------|
| `assignee` | 负责人用户名，`me` 表示当前用户 | `assignee: me` |
| `reporter` | 创建者用户名 | `reporter: zhangwei` |
| `status` | 状态名称 | `status: 进行中` |
| `priority` | 优先级 | `priority: 高` |
| `project` | 项目 Key | `project: DE4` |
| `sprint` | 迭代名称 | `sprint: "Sprint 33"` |
| `tag` | 标签名称 | `tag: Backend` |
| `type` | 工单类型 | `type: 缺陷` |
| `created` | 创建时间 | `created: today` |
| `updated` | 更新时间 | `updated: -7d..today` |
| `due` | 截止日期 | `due: ..today` |

**时间格式**

| 格式 | 说明 |
|------|------|
| `today` | 今天 |
| `-7d` | 7 天前 |
| `-1w` | 1 周前 |
| `-1m` | 1 个月前 |
| `2026-09-01` | 具体日期 |
| `-7d..today` | 最近 7 天（范围） |
| `..today` | 今天之前（无下限） |
| `today..` | 今天之后（无上限） |

**示例**

```
# 分配给我且优先级为高的工单
assignee: me priority: 高

# DE4 项目本周创建的缺陷
project: DE4 type: 缺陷 created: -7d..today

# 所有逾期未解决的工单
due: ..today status: 待处理
```

## 面板操作

**调整面板宽度**
拖拽面板右侧的分隔线（鼠标变为双向箭头时拖拽），可以调整查询面板的宽度。

**折叠/展开面板**
双击分隔线，或点击面板顶部的**收起**按钮，可以完全折叠查询面板，获得更大的工单列表显示区域。再次双击或点击**展开**按钮恢复。
