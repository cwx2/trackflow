# 工单管理

工单（Issue）是 TrackFlow 的核心对象，用于跟踪任务、缺陷、需求等所有工作项。

## 工单列表页

进入工单列表的方式：点击左侧导航栏的**问题**图标。

页面分为两个区域：

**左侧查询面板**（YouTrack 风格）
- 顶部搜索框：过滤已保存的查询列表
- 草稿区：未完成的工单草稿
- 项目区：收藏的项目快速筛选
- 标签区：收藏的标签快速筛选
- 已保存的搜索：命名查询列表

**右侧工单列表**
- 顶部工具栏：筛选、搜索、项目切换、创建工单、导出
- 工单表格：支持自定义列、多列排序、勾选批量操作
- 底部分页：可选每页显示 20/50/100 条

### 工单表格列

| 列名 | 说明 |
|------|------|
| 编号 | 工单唯一编号，格式 `{项目KEY}-{序号}`，如 `DE4-1617` |
| 类型 | 缺陷（红色方块）、任务（蓝色方块）、需求、史诗等 |
| 标题 | 工单标题，点击进入详情页 |
| 项目 | 所属项目，显示为项目 Key 徽章 |
| 负责人 | 当前负责处理的成员 |
| 状态 | 当前工单状态，以彩色标签显示 |
| Sprint | 所属迭代 |
| 优先级 | 紧急（红）/ 高（橙）/ 普通（蓝）/ 低（灰） |
| 截止日期 | 工单的截止时间 |
| 更新时间 | 最近一次修改的时间 |

> 点击表头可按该列排序，再次点击切换升序/降序。拖拽列头左侧的 ⠿ 图标可调整列顺序，点击右上角列配置图标可显示/隐藏列。

## 创建工单

### 方式一：点击「创建工单」按钮

点击工单列表右上角的**创建工单**按钮，右侧滑出创建面板，填写以下内容：

**基本信息（必填）**

| 字段 | 说明 |
|------|------|
| 项目 | 选择工单所属项目，创建后不可更改 |
| 标题 | 简洁描述问题或任务，最多 500 字符 |

**详细信息（可选）**

| 字段 | 说明 |
|------|------|
| 类型 | 缺陷 / 任务 / 需求 / 史诗 / 故事（由项目配置决定） |
| 状态 | 默认为工作流初始状态，通常是「待处理」或「Open」 |
| 优先级 | 紧急 / 高 / 普通 / 低，默认为「普通」 |
| 负责人 | 从项目成员中选择，支持搜索 |
| Sprint | 选择关联的迭代 |
| 截止日期 | 日期选择器 |
| 描述 | 富文本编辑器，支持 Markdown、@ 提及、代码块、图片上传 |
| 自定义字段 | 项目配置的额外字段（如故事点、环境、版本等）|

填写完毕点击**创建工单**按钮提交。

::: tip 草稿自动保存
填写过程中如果关闭面板或点击取消，已填写的内容会自动保存为**草稿**，显示在左侧查询面板的「草稿」区域。下次点击草稿可恢复编辑。
:::

### 方式二：键盘快捷键

在任意页面按 `C` 键（或点击左下角**创建**按钮）可快速打开创建面板。

## 工单详情页

点击工单列表中的工单标题，进入工单详情页。详情页分为三个区域：

### 顶部导航栏

- **面包屑**：显示所属项目和工单编号，点击可快速跳转
- **状态变更按钮**：直接点击可触发工作流转换，变更工单状态
- **投票**：点击 ⭐ 对工单投票，帮助团队了解影响范围
- **关注**：点击 👁 关注工单，后续会收到该工单的所有变更通知
- **更多操作**（⋮）：移动工单、删除工单等

### 主内容区（左侧）

**标题和描述**
- 点击标题可直接编辑（需有编辑权限）
- 描述区支持富文本，可插入代码块、图片、表格

**子工单**
- 点击「添加子工单」可创建隶属于当前工单的子任务
- 子工单列表显示各子工单的状态和负责人
- 支持父子嵌套最多 5 层

**工单链接**
- 点击「添加链接」建立与其他工单的关联关系
- 链接类型：关联 / 阻塞 / 被阻塞 / 重复 / 父子

**附件**
- 点击「添加附件」或直接拖拽文件上传
- 支持图片（在线预览）、PDF、文档、压缩包等
- 单文件最大 50MB，每个工单最多 50 个附件
- 可设置附件可见性（公开 / 仅特定角色可见）

**评论**
- 支持富文本评论，可 @ 提及项目成员
- @ 被提及的成员会收到站内通知和邮件通知
- 支持引用楼层、编辑、删除自己的评论
- 管理员可管理（删除/恢复）所有评论

### 活动流（底部标签页）

活动流记录工单的完整变更历史，包含：

| 标签 | 说明 |
|------|------|
| 活动 | 仅显示字段变更记录（状态、负责人、优先级等变更） |
| 全部 | 字段变更 + 评论 混合时间线 |
| 评论 | 仅显示评论 |
| 花费时间 | 工时登记记录 |
| 更多 | 可见性变更等其他记录 |

### 属性面板（右侧）

右侧面板显示工单的所有字段，点击任意字段值可直接修改（内联编辑）。

**基本属性**

| 字段 | 说明 |
|------|------|
| 项目 | 所属项目（不可修改） |
| 类型 | 工单类型 |
| 状态 | 当前状态 |
| 优先级 | 优先级 |
| 负责人 | 负责处理的成员 |
| 创建人 | 工单的创建者（不可修改） |
| Sprint | 所属迭代 |
| 截止日期 | 截止时间 |
| 父工单 | 上级工单（如有） |

**时间信息**
- 预估时间
- 花费时间（累计工时）
- 剩余时间

**其他**
- 标签：为工单添加分类标签
- 观察者：关注该工单的成员列表
- 自定义字段：项目配置的额外字段

## 批量操作

在工单列表勾选多个工单后，顶部工具栏变为**批量操作工具栏**，显示已选数量和以下操作按钮：

| 操作 | 说明 |
|------|------|
| 改状态 | 将选中工单批量切换到指定状态（受工作流约束） |
| 分配 | 将选中工单批量分配给某个成员 |
| Sprint | 将选中工单批量移入/移出迭代 |
| 优先级 | 批量修改优先级 |
| 标签+ | 批量添加标签 |
| 标签- | 批量移除标签 |
| 链接 | 批量创建关联关系 |
| 删除 | 批量删除（移入回收站） |
| 导出 | 导出选中工单为 CSV 或 Excel |
| 命令 | 打开快速命令对话框 |

点击左上角**取消选择**或按 `Esc` 退出批量操作模式。

---

## 快速命令（Apply Command）

在批量操作工具栏点击**命令**按钮（或按 `Ctrl+Alt+J`），弹出命令对话框，通过命令行语法快速修改多个字段：

```
assignee: 张伟 status: 进行中 priority: 高
```

**支持的命令字段**

| 字段 | 命令格式 | 示例 |
|------|----------|------|
| 负责人 | `assignee: 用户名` | `assignee: zhangwei` |
| 状态 | `status: 状态名` | `status: 进行中` |
| 优先级 | `priority: 优先级` | `priority: 高` |
| Sprint | `sprint: 迭代名` | `sprint: Sprint 1` |
| 标签 | `tag: 标签名` | `tag: Backend` |

## 导出工单

点击工单列表右上角的**导出**图标（↑），可将当前筛选条件下的工单导出为：

- **CSV**：纯文本，适合数据处理
- **Excel（.xlsx）**：带格式的表格，包含所有可见列和自定义字段值

::: warning 导出限制
单次导出最多 1000 条工单。如需导出更多，请先缩小筛选范围分批导出。
:::

## 工单状态变更

工单的状态变更受**工作流规则**约束，不是所有状态之间都可以自由切换。

**变更方式**
1. 在工单详情页顶部，点击当前状态旁的**变更状态**按钮
2. 在工单列表中，点击状态标签选择新状态
3. 在看板页面，拖拽工单卡片到另一列

**特殊规则**
- 某些转换只有特定角色可以执行（如「Testing → Done」只有测试人员可操作）
- 某些转换要求必须填写评论，会弹出评论对话框
- 若当前用户无权执行该转换，按钮会置灰并提示原因

## 工单可见性

在工单详情页右上角可以设置工单可见性：

- **公开**：项目所有成员均可查看
- **仅成员**：仅工单的负责人、创建者，以及 `project_admin`、`tech_lead` 角色可查看

::: info
观察者（observer）角色无法查看设置为「仅成员」的工单。
:::

## 回收站

删除的工单不会立即永久删除，而是进入**回收站**。

路径：左侧导航最底部 → **回收站**

- 回收站中的工单保留 **30 天**，到期后自动永久删除
- 有 `issue:delete` 权限的用户可以恢复工单
- `system_admin` 可以永久删除工单（不可恢复）

---

## 工单编号说明

每个工单的编号格式为 `{项目KEY}-{序号}`，例如：

- `TF-1`：TrackFlow 项目的第 1 个工单
- `DE4-1617`：开发环境4 项目的第 1617 个工单

工单编号**全局唯一且不可更改**，即使工单被删除，该编号也不会被重新使用。
