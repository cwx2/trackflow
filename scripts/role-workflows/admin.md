## 操作流程

**第一步：打开系统，进管理后台**

1. 访问 http://localhost:3000，登录
2. 找到管理后台入口（Admin 或设置图标）
3. 随机选一个今天要处理的情况

**第二步：处理用户权限（情况 A / C）**

进用户管理：
- 看用户列表，翻一翻，有没有显示异常的数据
- 找一个用户点进去看详情：他在哪些项目是什么角色？全局角色是什么？
- 随手调整一下某个用户的角色（比如把某个观察者升级为开发人员）
- 保存，刷新页面确认修改生效了
- 试着搜索一个用户名，搜索功能正不正常？

**第三步：查看工作流配置（情况 B）**

进工作流管理：
- 看现有状态列表，状态颜色、分类显示对不对？
- 找到"Testing → Done"的转换规则，看允许哪些角色操作
- 找到"In Progress → Code Review"的转换，看一下
- 随便修改一条规则看看操作是否流畅，保存是否有反馈
- 如果有"自动化规则"的 Tab，点进去看看里面有没有规则，界面是否正常

**第四步：管理自定义字段（情况 D）**

进项目设置 → 自定义字段：
- 看现有字段列表，类型、名称显示是否正常
- 尝试添加一个新字段：类型选单选，名称自己想一个有意义的
- 加几个选项值，保存
- 创建一个工单，确认新字段出现在表单里，选择后能保存
- 打开那个工单，确认自定义字段值显示正确

**第五步：看项目整体状态（情况 C / E）**

进项目列表：
- 几个项目各有多少成员？工单数量怎么样？
- 点进 DE4 或 MO1 项目的概览，看统计数据
- 有没有长期没有活动的工单？有没有超期的工单？

如果有 Webhook 配置（情况 E）：
- 找到 Webhook 管理入口
- 看有没有已有的配置，状态是否正常
- 尝试添加一个新的 Webhook 配置（URL 随便填一个测试地址）

**第六步：随手记录遇到的问题**

操作过程中遇到任何不对劲都记下来，比如：
- 管理后台某些页面进不去或者空白
- 用户列表加载很慢或数据显示不全
- 修改了角色但页面没有刷新
- 工作流配置界面操作很繁琐或不直观
- 自定义字段添加后在工单里找不到
- 某个保存操作没有任何成功/失败提示
- 搜索功能搜不到明明存在的用户
- 界面某处显示布局乱或者信息截断
